1. ธุรกิจเป็นของที่เปลี่ยนตลอด (Business Dynamics)

  • ธุรกิจไม่หยุดนิ่ง: สิ่งที่ขายดีวันนี้อาจหายไปในไม่กี่ปี คำถามที่ผู้บริหารต้องถามอยู่เสมอคือ "What's next?"
  • คู่แข่งไม่ได้มีแค่คนที่ขายของเหมือนเรา: คู่แข่งทางอ้อม (indirect competitor) คือคนที่แก้ปัญหาเดียวกันให้ลูกค้าด้วยวิธีอื่น เช่น ร้านอาหารแข่งกับอาหารแช่แข็งในร้านสะดวกซื้อ หรือแท็กซี่แข่งกับแอปเรียกรถ ส่วน Outsourcing Model ทำให้บริษัทเล็กจ้างคนอื่นผลิตแทนได้ แล้วเข้ามาแข่งได้ทันที
  • วิกฤตกับโอกาสมาพร้อมกัน: เหตุการณ์เดียวกันอาจเป็นวิกฤตของธุรกิจหนึ่ง แต่เป็นโอกาสของอีกธุรกิจหนึ่ง (สไลด์ยกตัวอย่าง The New Normal ใน Automotive Supply Chain) ธุรกิจที่ปรับ Operations ได้เร็วกว่าจะคว้าโอกาสได้ก่อน

5. Productivity (ผลิตภาพ): วัดว่าใช้ทรัพยากรคุ้มแค่ไหน

สูตรหลัก
Productivity = Output ÷ Input
ตัวแปรแปลว่าเอาตัวเลขมาจากไหน
Outputผลผลิตที่ได้ (ชิ้น หรือมูลค่าเงิน)ยอดผลิตหรือยอดขายในช่วงเวลานั้น
Inputทรัพยากรที่ใช้ (ชั่วโมงแรงงาน วัตถุดิบ เงิน)Partial ใช้ทรัพยากรตัวเดียว · Multifactor แปลงทุกตัวเป็นเงินก่อนแล้วค่อยรวมกัน
ตัวอย่างจากสไลด์ 1 · Partial (Labor) Productivity

คนงาน 2 คน ทาสีโต๊ะได้ 24 ตัวใน 8 ชั่วโมง

Input = 2 คน × 8 ชม. = 16 ชั่วโมงแรงงาน
Productivity = 24 ÷ 16 = 1.5 ตัว/ชั่วโมงแรงงาน
ตัวอย่างจากสไลด์ 2 · Multifactor Productivity (แปลงเป็นเงินก่อน)

ผลิต 200 ชิ้น ขายชิ้นละ $12 · วัตถุดิบชิ้นละ $6.50 · ใช้แรงงาน 40 ชม. ค่าแรงชั่วโมงละ $10

Output = 200 × 12 = $2,400
Input = (200 × 6.50) + (40 × 10) = 1,300 + 400 = $1,700
Productivity = 2,400 ÷ 1,700 = 1.41 (ใส่เงิน 1 บาท ได้ผลผลิตกลับมา 1.41 บาท)
ข้อดีข้อจำกัด
Partialหาข้อมูลและคำนวณง่าย เห็นชัดว่าทรัพยากรตัวไหนควรปรับปรุงไม่เห็นภาพต้นทุนทั้งหมด
Multifactor / Totalเห็นภาพรวม และเห็นต้นทุนเป็นตัวเงินตีมูลค่าบาง input ได้ยาก เช่น เครื่องจักรหรือพนักงานที่ใช้ร่วมกันหลายสินค้า

6. กลยุทธ์การผลิต 3 แบบ

แบบผลิตเมื่อไหร่สต๊อก / ความหลากหลาย / ความเร็วตัวอย่าง
Make-to-Stock (MTS)ผลิตล่วงหน้าตามพยากรณ์ แล้วเก็บเป็นสินค้าสำเร็จรูปสต๊อกเยอะ · แบบน้อย · ลูกค้าได้ของทันทีสินค้าอุปโภคบริโภค ชุดนักเรียน
Make-to-Order (MTO)ผลิตหลังได้ออเดอร์เท่านั้นสต๊อกน้อย · แบบหลากหลาย · ลูกค้ารอนานชุดแต่งงาน หุ่นยนต์อุตสาหกรรม
Assemble-to-Order (ATO)ผลิตชิ้นส่วนเก็บไว้ก่อนตามพยากรณ์ แล้วค่อยประกอบเมื่อได้ออเดอร์เป็นลูกผสมของ MTS กับ MTOคอมพิวเตอร์ เครื่องใช้ไฟฟ้า

ทดสอบความเข้าใจ

ร้านเบเกอรี่ทำเค้กวันเกิดตามแบบที่ลูกค้าสั่ง แต่เตรียมเนื้อเค้กไว้ล่วงหน้า เป็นกลยุทธ์แบบไหน
Assemble-to-Order เพราะชิ้นส่วน (เนื้อเค้ก) ทำไว้ก่อนตามพยากรณ์ แล้วค่อยแต่งหน้าตามออเดอร์ของลูกค้า

Naive Method

3.2 Moving Average (MA): เฉลี่ยยอดจริง n งวดล่าสุด

Moving Average
Ft = (At−1 + At−2 + … + At−n) ÷ n
ตัวแปรแปลว่าเอามาจากไหน
Ftค่าพยากรณ์ของงวด t—
At−1 … At−nยอดจริงของงวดที่ผ่านมาล่าสุด n งวด (ย้อนหลัง 1 งวด, 2 งวด, …, n งวด)ตารางยอดขาย
nจำนวนงวดที่เอามาเฉลี่ยโจทย์กำหนด เช่น "MA 2 สัปดาห์" แปลว่า n = 2
กดเครื่องคิดเลข: บวกยอดจริง n ตัวล่าสุด แล้ว ÷ n ไม่มีการคูณอะไรทั้งสิ้น · พอเลื่อนไปงวดถัดไป ให้ทิ้งตัวเก่าสุดแล้วเติมตัวใหม่เข้ามา จึงเรียกว่า "เคลื่อนที่"
ตัวอย่างจากสไลด์
MA 2 งวด: F3 = (A2 + A1) ÷ 2 = (980 + 1,000) ÷ 2 = 990
MA 2 งวด: F4 = (1,100 + 980) ÷ 2 = 1,040
MA 3 งวด: F4 = (1,100 + 980 + 1,000) ÷ 3 = 3,080 ÷ 3 = 1,026.7 ≈ 1,027

Weighted Moving Average
Ft = Wt−1At−1 + Wt−2At−2 + … + Wt−nAt−n
ตัวแปรแปลว่าเอามาจากไหน
At−1 …ยอดจริงของงวดก่อนหน้าตารางยอดขาย
Wt−1 …น้ำหนัก (weight) ของยอดแต่ละงวด ต้อง รวมกันได้ 1 (100%) และงวดที่ใกล้ปัจจุบันที่สุดได้น้ำหนักมากที่สุดโจทย์กำหนด

3.4 Exponential Smoothing (ES): แก้ค่าพยากรณ์เดิมด้วยส่วนที่พลาดไป

Exponential Smoothing
Ft = Ft−1 + α(At−1 − Ft−1)
หรือเขียนอีกแบบ: Ft = (1 − α)Ft−1 + αAt−1
ตัวแปรแปลว่าเอามาจากไหน
Ft−1ค่าพยากรณ์ของงวดก่อนงวดแรกโจทย์มักให้มา (ในสไลด์ให้ F4 = 1,020) งวดต่อ ๆ ไปใช้ค่าที่เราเพิ่งคำนวณได้
At−1ยอดจริงของงวดก่อนตารางยอดขาย

F6 = 996 + 0.2×(1,200 − 996) = 996 + 40.8 = 1,036.8 ≈ 1,037
F7 = 1,036.8 + 0.2×(1,050 − 1,036.8) = 1,039.4 ≈ 1,040

1. ลำดับชั้นของแผน (บนลงล่าง)

  1. Business Plan (1–2 ปี) จะขายอะไร ให้ใคร จุดขายคืออะไร ต้องใช้ทุนเท่าไหร่ คาดผลตอบแทนเท่าไหร่
  2. Aggregate Production Planning วางแผนระดับ "กลุ่มสินค้า" ให้ดีมานด์กับกำลังการผลิตสมดุลกัน
  3. Master Production Scheduling (MPS) วางแผนระดับ "สินค้าแต่ละตัว" ว่าต้องผลิตเท่าไหร่ ในงวดไหน
  4. Material Requirement Planning (MRP) แตกเป็นชิ้นส่วนตาม BOM ทำคู่กับ Capacity Requirements Planning (เช็คว่ากำลังการผลิตพอไหม)
  5. Purchasing สั่งซื้อและติดตามวัตถุดิบ
  6. Production ผลิตจริงและควบคุมหน้างาน

2. Planning Horizon: ต้องวางแผนล่วงหน้าไกลแค่ไหน

Planning Horizon

3. Planning Time Fence: 3 โซนของความยืดหยุ่น

โซนช่วงเวลาความหมาย
1 · Frozenตั้งแต่ปัจจุบันถึง Demand Time Fence (DTF)จองเครื่องจักร คน และวัตถุดิบให้ออเดอร์จริงแล้ว ถ้าเปลี่ยนแผนจะแพงมาก · ในตารางใช้ยอด Customer Order
2 · Slushyหลัง DTF ถึง Planning Time Fence (PTF)จองไว้บางส่วน ยังปรับได้บ้าง · ในตารางใช้ยอด Forecast
3 · Liquidหลัง PTF ไปแล้วเปลี่ยนแผนได้โดยแทบไม่มีต้นทุน

ก่อนทำ MPS ต้องตกลงกับลูกค้าไว้ 3 เรื่อง คือ Time Fence (ลูกค้าแก้ออเดอร์ได้ถึงเมื่อไหร่) · เงื่อนไขการสั่ง (สั่งขั้นต่ำ, Lot Size คงที่ หรือ Lot-for-Lot) · Lead Time

5. Bullwhip Effect

ปรากฏการณ์ที่ลูกค้าซื้อเพิ่มขึ้นนิดเดียว แต่ร้านค้าปลีกสั่งเพิ่มมากกว่านั้น ผู้ค้าส่งสั่งเพิ่มยิ่งกว่า และโรงงานผลิตเพิ่มมากที่สุด เหมือนสะบัดแส้ที่ปลายแส้แกว่งแรงกว่าด้ามจับ สาเหตุ 4 ข้อ:

  1. Lead Time ไม่แน่นอน ทุกฝ่ายจึงเผื่อสต๊อกกันชนของตัวเองซ้อนกัน
  2. ความคลาดเคลื่อนของพยากรณ์ ถูกส่งต่อและสะสมเป็นทอด ๆ
  3. Order Batching สั่งเป็นล็อตใหญ่เกินกว่าที่ใช้จริง
  4. ราคาและโปรโมชัน ทำให้คนซื้อกักตุน แล้วดีมานด์ตกฮวบหลังจบโปร

กฎการอ่านผล (ต้องจำให้ได้)

2. 5 หลักการของ Lean

4. ตัวเลขพื้นฐานของสายการผลิต

สูตรหลักของบท Lean
Cycle Time (CT) = เวลาระหว่างชิ้นงานที่ออกมาสองชิ้นติดกัน
Lead Time (LT) = Finish Time − Start Time = Processing Time + Waiting Time
Available Time = Shift Time − Planned Break (− Meeting)
Takt Time = Available Production Time ÷ Customer Demand
Capacity = Available Time ÷ Cycle Time
Little's Law: WIP = Throughput × Lead Time → Lead Time = WIP ÷ Throughput
ตัวแปรแปลว่าเอามาจากไหน / ข้อควรระวัง
CTทำได้จริงชิ้นละกี่วินาทีจับเวลาจากหน้างาน
Taktลูกค้าต้องการ 1 ชิ้นทุกกี่วินาที (Customer Clock)ใช้ เวลาผลิตที่มีจริง ไม่ใช่เวลาตามปฏิทิน · ใช้ ดีมานด์จริง ไม่ใช่ค่าพยากรณ์
Throughputอัตราที่ของออกจากระบบ (ชิ้น/วัน)ถูกจำกัดด้วยคอขวด
WIPงานที่ค้างอยู่ในระบบนับจากหน้างาน (ในแผนที่ VSM คือรูปสามเหลี่ยม)
C/OChangeover Time จากชิ้นดีชิ้นสุดท้ายของรุ่น A ถึงชิ้นดีชิ้นแรกของรุ่น BC/O ยาว → ต้องผลิต Batch ใหญ่ → WIP มาก → Lead Time ยาว

7. OEE และตัวชี้วัดประสิทธิภาพ

Overall Equipment Effectiveness
OEE = Availability × Performance × Quality
Availability (A) = Run Time ÷ Planned Production Time
Performance (P) = (Ideal Cycle Time × Total Count) ÷ Run Time
Quality (Q) = Good Count ÷ Total Count
ตัวแปรแปลว่าเอามาจากไหน
Planned Timeเวลาที่วางแผนให้เครื่องเดินโจทย์
Run Timeเวลาที่เดินจริง = Planned − Downtimeหัก Downtime ออกก่อน
Ideal CTเวลาต่อชิ้นตามสเปกของเครื่อง (ความเร็วสูงสุด)โจทย์
Total / Good Countชิ้นที่ผลิตทั้งหมด / ชิ้นที่ดีโจทย์
Six Big Losses: เครื่องเสีย (Breakdown) และ Setup ทำให้ A ต่ำ · หยุดสั้น ๆ (Minor Stop) และเดินช้า (Speed Loss) ทำให้ P ต่ำ · ของเสียจากกระบวนการ (Defect) และของเสียช่วงเริ่มเดินเครื่อง (Start-up) ทำให้ Q ต่ำ

Scrap % = Scrap Quantity ÷ Total Input × 100
Yield = Good Output ÷ Input · FPY = Good Output ที่ไม่ผ่านการแก้งาน ÷ Input
Productivity = Good Output ÷ Resource Input (ชิ้น/ชั่วโมงแรงงาน, ชิ้น/ชั่วโมงเครื่อง, ชิ้น/m², ชิ้น/kWh)
Simple Payback = Initial Investment ÷ Annual Net Cash Benefit
FPY สะท้อนสุขภาพกระบวนการได้ดีกว่า Yield เพราะการแก้งานทำให้ Yield สุดท้ายดูดีได้ · อย่าหยุดแค่ตัวเลข % ของ Scrap ให้ทำ Pareto แยกตามประเภทของเสีย สินค้า เครื่อง และกะ · ระวัง False Productivity: Output เพิ่มแต่ WIP เพิ่ม · เร็วขึ้นแต่ของเสียเพิ่ม · ลดคนแต่ OT เพิ่ม · Utilization สูงแต่ Lead Time ยาวขึ้น
